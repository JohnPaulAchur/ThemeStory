# ThemeStory

ThemeStory is a custom blog theme developed for LifeTech OCMS, featuring a responsive landing page, blog listing, blog details, and an admin dashboard.

### Features
- Responsive blog interface.
- Dynamic blog post loading and filtering through MdBlog.
- Blog details page with reading progress.
- Admin dashboard with management pages for posts, categories, comments, and tags.
- Comment moderation with live MdBlog API integration.

### Technologies
HTML, CSS, JavaScript, Jquery, Bootstrap, Bootstrap Icons, PHP, and MdBlog API.

Under development.
